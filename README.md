# Hermes Agent 赤本 — 『Hermes Agent Orange Book』日本語版

> 原書は HuaShu（花叔）の「橙皮書（Orange Book）」シリーズの一冊です。日本語版は、日本で学習本といえば赤本、という習慣に寄せて敢えて「赤本」を名乗ります。原書シリーズ名そのものは橙皮書のままです。

Nous Research のオープンソース AI Agent フレームワーク [Hermes Agent](https://github.com/NousResearch/hermes-agent) の実践ガイド『Hermes Agent 2.0: The Complete Guide』（著者 HuaShu／花叔）の日本語訳です。

- 原書リポジトリ: [alchaincyf/hermes-agent-orange-book](https://github.com/alchaincyf/hermes-agent-orange-book)
- 翻訳元: 中国語版第3版 v261020（Hermes Agent v0.22.2 ベース）を主たる翻訳元とし、英語版第2版 v260607 を参照
- ライセンス: 原書は MIT ライセンスで公開されており、本訳も同ライセンスに基づいて作成・公開します（[LICENSE](LICENSE) に原著者の著作権表示とライセンス文を収録）
- 翻訳: Munku Haniwa（制作協力: Muse）

## 原文の時点について

原文の数値・事実は、中国語版第3版の基準時点（Hermes Agent v0.22.2、2026年10月）のものです。Hermes Agent は開発が速いため、最新の仕様は [公式ドキュメント](https://hermes-agent.nousresearch.com/docs/) を確認してください。

§03 については、英語版第2版の原文に著者自身による訂正（Errata）があり、中国語版第3版では本文自体が訂正済みです。本訳はその訂正済み本文を正本として訳しています（詳細は §03 の訳者注）。
